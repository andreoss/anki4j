= anki4j

Java library to read, create and modify flashcard decks in the standard
SQLite collection format.

== Build

Needs a Java 21 JDK and Maven.

[source,bash]
----
mvn -B package
----

== Test

[source,bash]
----
mvn -B test
----

== Coverage

[source,bash]
----
mvn -B verify
----

== Use

[source,xml]
----
<dependency>
  <groupId>io.github.andreoss</groupId>
  <artifactId>anki4j</artifactId>
  <version>0.6.2</version>
</dependency>
----
